# Analysis map and external inputs

All paths below are relative to the repository root. Run `prepare_configuration.py` first. No input files, downloaded metadata, intermediary products or plotted data are supplied by this repository. Filenames referenced inside scripts specify their input contracts; download helpers and source accessions identify the original providers. Source annotations, clinical sheets, pairing manifests and any manually curated mappings must be obtained or reconstructed separately before a dependent stage can run.

## Paths for supplementary cell-line inputs

`revision14/analyze_DepMap.py` uses `MITOTEMPORAL_DEPMAP_DIR`, defaulting to `revision14/raw/depmap/`. It expects `CRISPRGeneEffect.csv`, `Model.csv`, and `OmicsExpressionTPMLogp1.csv`, plus the separately retrieved release inventory in `revision14/metadata/`.

`revision14/analyze_proteomics.py` uses `MITOTEMPORAL_CCLE_PROTEOME`, defaulting to `revision14/raw/ccle_prot/protein_quant_current_normalized.csv.gz`. Original sample annotations and other cohort source files are also required. The download and processing code identifies source URLs; inputs are intentionally not mirrored here.

## Figures

Earlier-stage `build_figures.py` scripts generate plotting inputs and historical artwork consumed by subsequent assemblies. The final four main figures are assembled by `revision12/build_figures.py` (Figures 1, 2, 4 and inherited supplements) and `revision13/build_rebalanced_figure3.py` (Figure 3 and related supplementary rearrangement). `revision14/build_extension_figures.py` adds supplementary extension figures. These scripts require local source tables and, for inherited artwork, locally regenerated earlier figures. Those assets are not included in the repository.

## Reproducibility limits of a code-only release

This repository exposes the implemented algorithms and source-retrieval logic. It does not distribute frozen downloaded inputs, curated metadata, processed objects, or output tables. Exact numerical reproduction therefore requires the same input versions and clinical/sample mappings. Obtain these from the original providers and preserve checksums locally; do not infer that syntax/helper checks verify a complete fresh data reconstruction.
